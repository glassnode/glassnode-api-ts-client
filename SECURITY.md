## Reporting a vulnerability

Don't open a public issue. Report it privately:

- **GitHub:** the repository's **Security** tab → **Report a vulnerability**
  ([private vulnerability reporting](https://github.com/glassnode/glassnode-api-ts-client/security/advisories/new)).
- **Email:** security@glassnode.com, if you can't use GitHub.

Include the affected version, steps to reproduce and the impact. Glassnode has no bug bounty
program.

## Supported versions

Only the latest release receives security fixes.
